# 易经卜卦应用

一款为年轻人设计的易经卜卦网站，包含随机爻画卜卦、卦象详解和推荐事宜等功能。

## 功能特性

- 🎯 随机爻画卜卦
- 📖 卦象详解
- ✅ 适宜/忌讳事宜推荐
- 🌙 深色/浅色主题切换
- 📱 流畅的页面切换动画

## 技术栈

- React + TypeScript
- Tailwind CSS
- Vite

## 开始使用

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

## 部署

本项目配置了 Netlify 部署，只需推送到 GitHub 仓库即可自动部署。
